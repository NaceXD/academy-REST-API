# Academy REST API 📚

Современное веб-приложение для автоматизации учёта студентов и образовательных курсов. Проект спроектирован с использованием чистой архитектуры и связи таблиц "Многие-ко-многим".

## 🛠 Стек технологий
* **Backend:** FastAPI (Python 3.10+)
* **Database & ORM:** SQLite, SQLAlchemy 2.0+ (Декларативный стиль)
* **Validation:** Pydantic v2 (EmailStr, ConfigDict)
* **Testing:** Pytest (Интеграционные тесты со своей БД в памяти/файле)

## 🚀 Функционал проекта
* Полноценный CRUD для управления студентами и курсами.
* Безопасная валидация входных данных (проверка формата email).
* Защита от дубликатов на уровне бизнес-логики (проверка уникальности email перед записью).
* Оптимизация запросов к БД: встроенная пагинация списков (`limit` и `offset`).
* Связывание сущностей: запись студента на курс через промежуточную таблицу.

## 📦 Как запустить проект локально

1. Клонируйте репозиторий:
```bash
git clone https://github.com
cd имя_репозитория
```

2. Cоздайте и активируйте виртуальное окружение:
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Mac/Linux:
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Запустите сервер:
```bash
uvicorn main:app --reload
```
После запуска интерактивная документация API (Swagger UI) будет доступна по адресу: http://127.0.0.1/docs

## 🧪 Запуск автоматических тестов
Проект полностью покрыт интеграционными тестами. Для запуска тестов выполните:
```bash
pytest -v
```
